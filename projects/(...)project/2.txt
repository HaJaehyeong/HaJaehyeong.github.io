### 프로젝트 개요
생산 현장에서 발생하는 가공 상태, 작업자 근무 시간, 장비稼動 정보 등을 실시간으로 수집·분석하여 생산성과 근무 효율을 높이는 스마트 제조 서비스입니다.
서비스 안정성과 UI 일관성을 확보하기 위해 Vue.js 기반 시스템을 Next.js(React) 로 전면 리뉴얼하였습니다.

### 팀 구성
총 5명 (PM 1명, Back 1명, Front 1명, Server 1명, SE 1명)

### 주요 역할 및 기여
- **Next.js 기반 UI 리뉴얼 및 아키텍처 개선**
    - 기존 Vue.js 구조를 React 및 Next.js로 재구성하여 렌더링 성능과 유지보수성을 향상시켰습니다.
- **WebSocket 기반 실시간 데이터 모니터링 시스템 구축**
    - 장비 상태, 가공 속도, 작업 시간 등의 데이터를 실시간으로 송수신하여 생산 현황을 시각적으로 파악할 수 있는 모니터링 페이지를 개발하였습니다.
- **관리자(Admin) 화면 설계 및 효율적 유지보수 체계 구축**
    - UI/UX 일관성 확보와 재사용 가능한 컴포넌트 설계를 통해 유지보수 및 확장 비용을 절감하였습니다.
- **Agile(Scrum) 프로세스 도입 및 일정 관리 주도**
    - Daily Scrum, Sprint Review, Retrospective를 도입하여 협업 효율과 일정 관리 체계를 개선하였습니다.

### 성과 및 개선 효과
- 서비스 리뉴얼 후 버그 관련 고객 문의 월 16건 0~1건으로 감소 (약 94% 감소)

- 코드 구조 개선 및 컴포넌트 재사용률 증가로 유지보수 효율 향상

### Next.js 기반 프로젝트 구조 설계 및 개발 주도 경험
바로 팩토리는 기존 Vue.js 기반 프로젝트에서 Next.js(React)로 마이그레이션하는 작업으로 시작되었습니다.
Vue.js는 간단한 토이 프로젝트에서만 다뤄본 경험이 있었지만, 코드를 읽고 이해하는 데에는 무리가 없었습니다.
React는 독학을 통해 간단한 페이지를 구현할 수 있는 수준이었으나, 단순히 동작하는 코드보다는
**누구나 읽기 쉽고 이해할 수 있는 코드**를 중요하게 생각하는 제 성향 때문에 구조 설계부터 고민이 많았습니다.
Next.js 프로젝트의 구조를 어떻게 구성할지, 컴포넌트 분리 기준, 디렉토리 설계, API 호출 위치 등
작은 부분 하나하나까지 가독성을 좋게 만들기 위해 판단과 선택이 필요했습니다.
이를 극복하기 위해 Next.js 공식 문서의 Getting Started를 처음부터 끝까지 [실습](https://github.com/HaJaehyeong/study)하며 학습했고,
예제 코드와 실전 샘플 프로젝트를 적극적으로 참고하며 **유지보수와 확장에 용이한 구조**를 만들고자 노력했습니다.
다만, 프론트엔드 개발자가 저 혼자였기에 코드를 공유하며 피드백을 받을 수 있는 기회가 부족했습니다.
이 한계를 보완하기 위해 추후 사이드 프로젝트에 참여하여 다른 개발자와 코드 구조나 구현 방식을 주고받으며
